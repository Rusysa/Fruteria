Endpoints de la API REST

POST /api/auth/login Iniciar sesión — Devuelve token JWT Público
GET /api/products Obtener todos los productos Público
GET /api/products/:id Obtener un producto por ID Público
POST /api/products Crear nuevo producto 🔐 JWT
PUT /api/products/:id Actualizar producto existente 🔐 JWT
DELETE /api/products/:id Eliminar un producto 🔐 JWT

Configuración del Servidor (server.js)

const express = require('express'); const cors = require('cors'); const path = require('path'); const app = express(); const PORT = 3000; // Middleware app.use(cors()); app.use(express.json()); // Archivos estáticos del frontend app.use(express.static(path.join(__dirname, '../frontend'))); // Rutas de la API app.use('/api/products', productRoutes); app.use('/api/auth', authRoutes); // Iniciar servidor en 127.0.0.1 app.listen(PORT, '127.0.0.1', () => { console.log(`Servidor en http://127.0.0.1:${PORT}`); });

Guía de Instalación Paso a Paso

1

Verificar Requisitos

Asegúrate de tener instalados Node.js v16+ y MySQL v8+.

node --version # Debe mostrar v16.x.x o superior mysql --version # Debe mostrar 8.x.x o superior
2

Crear la Base de Datos MySQL

Ejecuta el script SQL para crear la base de datos y los datos iniciales.

# Opción 1: Desde la terminal mysql -u root -p < database/database.sql # Opción 2: Desde MySQL Workbench # Abre database/database.sql y ejecuta el script
3

Configurar Credenciales de MySQL

Edita el archivo backend/config/db.js con tus credenciales locales.

// backend/config/db.js const connection = mysql.createConnection({ host: '127.0.0.1', user: 'root', // ← Tu usuario password: '', // ← Tu contraseña database: 'fruteria_veracruzana' });
4

Instalar Dependencias npm

Instala todos los paquetes necesarios del backend.

cd backend npm install # Instala: express, cors, mysql, bcryptjs, jsonwebtoken
5

Iniciar el Servidor

Lanza el servidor Express en el puerto 3000.

# Modo producción npm start # Modo desarrollo (recarga automática) npm run dev # Salida esperada: Servidor corriendo en http://127.0.0.1:3000 Conexión a la base de datos establecida.
6

Abrir en el Navegador

Visita las siguientes URLs en tu navegador.

# Sitio web principal http://127.0.0.1:3000 # Panel de administrador http://127.0.0.1:3000/admin # API de productos (JSON) http://127.0.0.1:3000/api/products
